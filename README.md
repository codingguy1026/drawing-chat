# 미니챗봇

Floating Island UI를 가진 가벼운 브라우저 기반 미니 챗봇 프로토타입입니다.

## 현재 기능

- 파일 하나로 실행되는 정적 HTML 앱
- Floating Island UI 디자인
- 이전 채팅 사이드바
- 새 채팅 생성
- 채팅방 삭제
- 현재 대화 초기화
- 채팅방별 타입 선택
  - ☁️ 말랑 대화
  - 💻 코딩 도움
  - 📚 공부 모드
  - 💡 아이디어
  - ⚡ 짧은 답변
- localStorage 기반 대화 저장
- 입력 중 점 애니메이션
- 메시지 시간 표시
- 한글 조합 중 Enter 중복 입력 방지
- 사용자 입력 XSS 방지

## 실행 방법

`index.html` 파일을 브라우저에서 열면 바로 실행됩니다.

서버, 빌드 도구, 외부 라이브러리가 필요 없습니다.
